## 🎬 Urutan Alur Presentasi Interaktif

### Langkah 1: Eksplorasi Halaman Publik (Role: Pengunjung)
1. Buka browser pada `http://127.0.0.1:5198/`.
2. Perlihatkan **Hero Section** modern yang memadukan identitas resmi Elwafa Center, headline terarah, foto asli santri, dan lencana akreditasi.
3. Scroll ke bawah menuju **Katalog Program Studi**. Tunjukkan filter kategori (Perguruan Tinggi, Sekolah Menengah, Bahasa & Al-Qur'an) serta indikator kuota santri.
4. Perlihatkan **7 Alur Perjalanan Santri**, dokumentasi kegiatan (karantina Ciamis, tryout nasional), dan FAQ.
5. Klik tombol **Daftar Sekarang** di navbar atau hero.

### Langkah 2: Pendaftaran Santri Baru (Admission Onboarding)
1. Muncul modal formulir pendaftaran santri baru.
2. Masukkan data simulasi (misal: *Zulfikar Hakim*, *zulfikar@gmail.com*, *081299887766*, pilihan program: *Bimbingan Kuliah S1 Al-Azhar*).
3. Klik tombol **Lanjut ke Portal Mahasiswa**.
4. Sistem otomatis membuat akun santri baru dan mengalihkan layar langsung ke **Portal Mahasiswa**.

### Langkah 3: Pengalaman Mahasiswa (Role: Mahasiswa)
1. Tunjukkan kartu status: pendaftaran baru berstatus **PENDING (Menunggu Verifikasi)**.
2. Buka tab **Biodata Santri**:
   - Tunjukkan formulir multi-step (Identitas Pribadi → Riwayat Pendidikan → Data Orang Tua → Review).
   - Klik **Simpan & Ajukan Verifikasi**.
3. Buka tab **Dokumen Berkas**: perlihatkan checklist dokumen ijazah, paspor, dan foto.
4. Buka tab **Jelajahi Program**: tunjukkan kemudahan santri melihat rincian kurikulum atau berganti peminatan.

### Langkah 4: Beralih ke Peran Admin Verifikator (Role: Admin)
1. Pada floating demo bar di bagian bawah, klik tombol **Admin**.
2. Jelaskan metrik ringkasan KPI di bagian atas:
   - Total Pendaftar
   - Antrean Perlu Verifikasi (Pending)
   - Disetujui (ACC)
   - Perlu Revisi Dokumen
3. Pada tabel pendaftar, temukan santri yang baru didaftarkan atau pilih santri yang ada (misal: *Faris Ramadhan*).
4. Klik tombol **Review Berkas**.

### Langkah 5: Eksekusi Keputusan Verifikator
1. Modal inspeksi berkas terbuka menampilkan seluruh data pribadi, asal madrasah, kontak wali, dan dokumen santri.
2. Demonstrasikan 2 skenario aksi:
   - **Skenario A (Minta Revisi):** Klik tombol kuning *Minta Revisi Dokumen*. Ketikkan catatan: *"Mohon unggah ulang scan legalisir ijazah yang lebih tajam dan terbaca jelas."* Klik Eksekusi.
   - **Skenario B (Setujui / ACC):** Klik tombol hijau *Setujui (ACC Pendaftaran)*.
3. Status pendaftar di tabel seketika berubah menjadi **Disetujui (ACC)** atau **Perlu Revisi**.

### Langkah 6: Bukti Sinkronisasi Nyata di Portal Mahasiswa
1. Di floating demo bar, klik kembali tombol **Mahasiswa**.
2. Tunjukkan bahwa banner status mahasiswa seketika berubah sesuai keputusan admin yang baru saja diambil!
3. Jika berstatus *Disetujui*, tombol unduh bukti kelulusan aktif. Jika *Perlu Revisi*, catatan perbaikan dari admin langsung muncul di dashboard santri.

### Langkah 7: Reset Demo
1. Jika ingin mengulang presentasi dari awal untuk audiens lain, klik icon **RotateCcw (Reset)** di floating bar. Data demo akan kembali bersih seperti semula.
